“氛围词（静态氛围）”本质上就是：不描述动作，只负责“让画面有情绪、有感觉”的词。
它介于“画面关键词”和“情绪表达”之间，但重点是——它不会推动时间变化，也不会让画面动起来。
🧠 一句话理解
👉 氛围词 = “这张画给人的感觉是什么”
不是“发生了什么”，而是“看起来像什么情绪”
🎭① 静态氛围词是什么类型？
✔ 1. 情绪类（最核心）
孤独感
压抑感
宿命感
温柔感
治愈感
紧张感
神秘感
绝望感
👉 这些都是“感觉”，不是动作
✔ 2. 电影质感类
电影级质感
史诗感
高级感
超写实
纪录片风格
沉浸感
👉 这是“视觉评价”，不是内容
✔ 3. 时间/空间氛围（静态状态）
寂静夜晚
空旷街道
无人城市
末日废墟
雨夜街头
黄昏时分
👉 注意：这里只描述“状态”，不是动作
✔ 4. 色彩情绪（很重要）
冷色调
暖色调
低饱和
高对比
蓝色忧郁调
霓虹光污染
⚠️② 为什么叫“静态氛围”？
因为它满足三个条件👇
❌ 不做这些事：
不移动（不是动作）
不拍摄（不是镜头）
不变化过程（不是动态）
✔ 只做一件事：
定义画面“基调”
🎬③ 对比一下就懂了

在即梦、AI短剧、AI漫剧里：
剧情（Story）≠ 对白（Dialogue）
很多新手把剧情和对白混为一谈，其实它们是两个不同层级。
🎬 什么是剧情？
剧情就是：
人物发生了什么事。
或者更简单：
故事的发展过程。
例如：
只有对白
Plain text
“你为什么骗我？”
这不是剧情。
因为观众不知道发生了什么。
加上剧情
Plain text
少女发现未婚夫与闺蜜在一起。

她冲进酒店房间。

愤怒质问：

“你为什么骗我？”
这才是剧情。

【画面】

【动作】

【镜头】

【环境动态】

【氛围】
绝望感转为希望感。

【对白】
“原来，我才是真正的天命之子。”
这里：
剧情 = 故事
画面 = 场景
动作 = 表演
镜头 = 摄影
环境 = 特效
氛围 = 情绪
对白 = 台词
最简单记忆法
Plain text
剧情 = 发生什么事
画面 = 长什么样
动作 = 怎么动
镜头 = 怎么拍
环境 = 周围怎么动
氛围 = 什么感觉
对白 = 说什么
做AI漫剧、小说推文、真人短剧时，剧情是骨架，对白是血肉，画面和动作是外表。 没有剧情，再漂亮的画面也很难形成连续追更的短剧。
